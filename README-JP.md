# Summer in Heat VR Mod

> [!IMPORTANT]
> これは **UnityVRMod** フレームワークの専用バージョンであり、Miconisomi の **Summer in Heat**（夏のサカり）向けに特別に調整されています。

---

## ✨ 機能

- **ネイティブ 6DOF VR 体験**: **OpenXR** による完全な 6 自由度トラッキング。
- **没入型インタラクション**: VR コントローラー向けに最適化された 3D UI インタラクションシステム。
- **高度な移動システム**: VR テレポートや快適性を重視した視点操作（スナップ/スムーズ回転）を搭載。
- **動的 UI 管理**: VR 内でゲーム内 UI パネルの位置変更や拡大縮小が可能。
- **シームレスな視点**: 最適化された一人称カメラバインディングと固定シーン遷移。
- **物理インタラクション対応**: 髪、胸、スカートなどの物理演算が有効な部位とのインタラクション。
- **スカート操作対応**: 物理演算衣類（主にスカート）に近づいた際、グリップボタンを押すことで近くの衣類を操作できます。

  - *Pico 3/4 のテストは他のユーザーからの報告によるものです。*

## 🚀 インストール

1. **BepInEx 5 のインストール**: x64 版の BepInEx 5 がゲームディレクトリにインストールされていることを確認してください。
2. **Mod ファイルの配置**: リリースの内容をゲームのルートフォルダ（`『夏のサカり』起動ランチャー.exe` と同じフォルダ）に展開します。
3. **設定**:
   - 初回起動時に設定ファイルが自動生成されます。
   - 手に追従する UI パネルの距離は、`BepInEx/config/com.newunitymodder.unityvrmod.cfg` の `OpenXR UI Panel Hand Forward Offset` で変更できます。既定値は `0.25` m、設定範囲は `0`～`0.75` m です。変更後はゲームを再起動してください。
4. **以下のいずれかの方法で VR を起動**:
   - VR ランタイム（Meta Quest Link や Virtual Desktop など）を起動します。
   - ゲームを起動し、**F11** を押して VR モードを切り替えます（切り替えキーは設定ファイルで変更可能です）。
   - または **start_vr.cmd** を直接起動します。

## 🛠️ パススルー機能

**切り替え操作:** F9（設定で変更可能）、トリガー + X、またはトリガー + A。

切り替え操作で、パススルーと背景色を切り替えます。ネイティブパススルーに対応している場合は、ネイティブパススルーと背景色の変更を同時に有効にします。ネイティブパススルーには背景色の変更が必要なためです。ネイティブパススルーに対応していない場合は、Virtual Desktop でパススルーを設定しやすくするため、背景色のみを変更します。

### 対応状況

ネイティブパススルーには、ヘッドセットとランタイム（ストリーミングソフトウェア）の両方が `XR_FB_passthrough` に対応している必要があります。

現在は Quest 3 と Meta Horizon Link の組み合わせに対応しています。Virtual Desktop 使用時は対応していません。その他のデバイスについては各自でお試しください。

### 使用手順

パススルーを有効にするには、まず **5** を押してゲーム内の背景を非表示にし、その後、切り替え操作で VR パススルーを有効にします。

カスタムキャラクターのシーンと 2D 会話シーンでは、ネイティブパススルーと背景色の変更にはまだ対応していません。

### Virtual Desktop 使用時の注意

推奨する Virtual Desktop 設定: Color は黒 `(0, 0, 0)`、Similarity `= 0`、Smoothness `= 1%`、Passthrough Opacity `= 100%`。

プラグイン側の設定でも、背景色を `0 0 0 255` に設定する必要があります。

他の色の組み合わせも試せますが、上記の設定がテストでは最も良好な結果でした。

## 🎮 操作方法（Oculus/Meta Touch）

> [!TIP]
> `OpenXR Control Hand` で移動とインタラクションの手を切り替えます。`OpenXR UI Panel Follow Hand` で UI パネルが追従する手を切り替えます。**X（左）/ A（右）** をダブルクリックすると、実行時にパネルの追従手を切り替えられます。

| アクション | VR コントローラー入力 |
| :--- | :--- |
| **テレポート照準** | **右スティック ↑**（常に右手） |
| **テレポート確定** | **右トリガー**（常に右手） |
| **スナップ回転** | **右スティック ←→**（常に右手） |
| **スムーズ回転** | **右スティック押し込み（長押し）** + ←→ 移動 |
| **スムーズ移動 / 歩行** | **左スティック**（カメラ相対、速度設定可能） |
| **追従 / フリーモード切替** | **左スティック押し込み** |
| **ビューポート移動** | **グリップ（いずれかの手）長押し** + ドラッグ |
| **UI 固定 / 追従切替** | **Y（左）/ B（右）クリック** |
| **パネル追従手の切替** | **X（左）/ A（右）ダブルクリック** |
| **UI パネル表示切替** | **X（左）/ A（右）クリック** |
| **UI クリック / 選択** | **いずれかのトリガー**（最初の押下で自動切替） |
| **UI パネルのサイズ変更と移動** | **トリガー（境界上）** + ドラッグ |
| **ペッティング操作** | **トリガー（いずれかの手）** + 手を対象に近づける |
| **サブカメラ移動モード切替** | **A（右）長押し** |
| **サブカメラ移動** | **右スティック**（サブカメラ移動モード ON 時） |
| **サブカメラ回転** | **右スティック押し込み長押し** + **右スティック** |
| **サブカメラ高さ調整** | **A タップ（上）/ B タップ（下）**（サブカメラ移動モード ON 時） |

### UI インタラクション

- **どちらのトリガーでも UI をクリック可能**: 左右いずれかの手のトリガーを押すと、最初に押した手がクリック手として固定され、もう一方の手がクリックするまで維持されます。
- **パネル追従手**: X（左）または A（右）をダブルクリックして、UI パネルが追従する手を切り替えます。パネルの位置は移動に使用する操作手とは独立しています。
- **パネル表示**: X（左）または A（右）をクリックして UI パネルの表示/非表示を切り替えます。Hybrid2D シーンでは無効です。

### ビューポート移動

1. いずれかのコントローラーの**グリップ**を長押しします。
2. 手を動かしてワールドをドラッグします。
3. 離すと停止します。

### 追従 / フリーモード

- **追従モード**: VR が元のゲームカメラの位置と水平方向のヨー変化に追従します。
- **フリーモード**: VR が現在のビューポートを維持し、元のゲームカメラの動きから独立します。**左スティック**、**グリップドラッグ**、テレポート、回転で手動調整します。
- **左スティック押し込み**で実行時にモードを切り替えます。

### ペッティング操作

1. いずれかのコントローラーを対象の身体部位に近づけます。
2. 有効な対象が検出されると、アイコンが**青色**に変わります。
3. **トリガー**を押してインタラクションすると、アイコンが**オレンジ色**に変わります。
4. ゲームのフリーモード時のみ動作します。

### サブカメラ操作

1. **A を長押し**してサブカメラ移動モードを ON/OFF します。
2. 移動モード ON 時に**右スティック**を動かしてサブカメラを移動します。
3. **右スティック押し込み**を押しながらスティックを動かして回転します。
4. 移動モード中に **A をタップ**で高さを上げ、**B をタップ**で高さを下げます。
5. 移動モード ON 時はサブカメラの枠が赤く表示されます。

## ⚠️ 現在の状況とロードマップ（2026年2月）

> [!NOTE]
> この Mod は現在も活発に開発中です。以下は既知の制限事項と予定されているアップデートです。

- **ADV シーン**: 現在は 2D 投影として表示されます。VR での視覚効果は PC 版と異なる場合があり、今後のアップデートで対応予定です。
- **UI 統合**: 一部のダイアログアイコンは現在、直接クリックではなくメイン UI パネル経由での操作が必要です。
- **パフォーマンス注意**: 高いグラフィック設定やエフェクトは VR のフレームレートに大きく影響します。安定性のために注意して調整してください。
